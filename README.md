# Piu Search

Android 端末に入っているアプリを、日本語の読み・表記ゆれ・ジャンルで探せる検索アプリ。ホーム画面は置き換えず、デジタルアシスタントやクイック設定タイルから呼び出して使う。日本語の端末での名前は「Piu アプリ検索」。

## できること

- 読みで引ける。「のりかえ」「乗り換え」「乗換」「norikae」のどれでも、乗換案内のアプリが見つかる（ひらがな・カタカナ・漢字・ローマ字、送り仮名の違いを吸収する）
- 英字のブランド名を読みで引ける。「やふー」で Yahoo! の、「ぐーぐる」で Google のアプリが出る
- ジャンルで引ける。「ちず」で、Google マップも Yahoo!マップも見つかる
- 提供元で引ける。「楽天」で、名前に「楽天」を含まない楽天の系列のアプリも（名前で当たるアプリの後に）出る
- 学習する。一度別の語で探して開いたアプリは、次からその語でも出る。覚えた語は設定の画面で確かめ、消し、ファイルに書き出せる
- 「すべてのアプリ」の一覧（名前の順。かな・漢字は読みの五十音順）
- 検索窓を画面の下（片手で届く位置）か上に置ける
- 仕事用プロファイルのアプリも探せる（「個人用｜仕事用」の切り替えか、混ぜて出すかを選べる）
- 呼び出しの入口: ホームのアイコン・デジタルアシスタント（画面の隅からのスワイプや電源ボタンの長押し）・クイック設定タイル

対応する端末は Android 8.0（API 26）以上。素の Android と GrapheneOS の両方で動くことを目指していて、Google のサービスには依存しない。

## 権限と通信

- **ネットに接続しない。** `INTERNET` の権限を持たない。検索・学習・ジャンルの判定は、すべて端末の中で行う
- 端末のすべてのアプリを見る権限（`QUERY_ALL_PACKAGES`）を持たない。見るのは、ホームに出る（起動できる）アプリだけ
- 学習した語と設定は、Google ドライブへの自動バックアップから外している。書き出しは、保存先を自分で選ぶ（Android のファイルの保存画面を使うので、ストレージの権限は要らない）

集める情報と送る情報はない。詳しくは [PRIVACY.md](PRIVACY.md)。

## 入れ方

配布の準備中で、まだ署名つきの版を公開していない。いまは、下の「ビルド」で APK を作り、`adb install` で入れる。

最初に開いたときの案内から、呼び出しの入口を設定できる（設定の画面の「呼び出しの設定」からも開ける）。

- デジタルアシスタント: 端末の設定の「デジタル アシスタント アプリ」でこのアプリを選ぶと、端末によっては、画面の下の隅からのスワイプや電源ボタンの長押しで開ける
- クイック設定タイル: タイル「アプリ検索」を足すと、どの画面からでも開ける

## ビルド

Linux（Ubuntu）で確かめている。必要なのは Java の実行環境（JRE 17 以上）と Android SDK。JDK は要らない（Gradle が JDK 21 を取得して使う）。SDK の入れ方は [CONTRIBUTING.md](CONTRIBUTING.md#開発環境を作る) にある。

```bash
echo "sdk.dir=$HOME/Android/Sdk" > local.properties
./gradlew :app:assembleDebug   # app/build/outputs/apk/debug/app-debug.apk
./gradlew check                # 書式・Lint・テスト・網羅率・ライセンスなどの検査
```
