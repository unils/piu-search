# 要件

2026-10-27 に、メンテナと AI の相談から整理した。メンテナが挙げたことと、AI が補ったことを分けて書く。

## 背景

Pixel Launcher のアプリ検索は、次の場合にヒットしない。

- 表記ゆれ（カタカナとひらがな、英字とカタカナ）
- 変換の揺れ（漢字とかな）
- 送り仮名の違い（「乗換案内」と「乗り換え案内」）

既存のランチャーや検索アプリを調べたが、これを解決するものは見つからなかった（[existing-apps.md](research/existing-apps.md)）。

## YomiLauncher を試した結果（2026-10-27）

メンテナが YomiLauncher（[existing-apps.md](research/existing-apps.md)）を実機で試し、「ほぼ不満がない」と評価した。読みで引けるだけで、上の不満はほぼ解決した。残った不満は次の 4 点で、これがこのアプリの要件の中心になる。

| # | 不満・要望 | 原因 |
|---|---|---|
| T1 | 広告が出る | AdMob を載せている |
| T2 | 「やふー」で Yahoo 系のアプリの一覧が出ない（「Y!」なら出る） | 英字のブランド名の読みが辞書にない。辞書には Google・LINE・PayPay・Amazon などはあるが、Yahoo がない（2026-10-27 に `dictionary.json` で確認） |
| T3 | 検索窓は画面の下に欲しい | 片手で親指が届く位置 |
| T4 | 学習機能が欲しい | 「学習機能をうまいことつけられれば、それだけで OK」（メンテナ） |

ジャンル検索（U2）は引き続き要件に含める（2026-10-27 に一度優先度を下げたが、メンテナが「後回しはまだ早い」と撤回）。

## メンテナが挙げた要件

| # | 要件 | 補足 |
|---|---|---|
| U1 | 読みで引ける。表記ゆれ・変換の揺れ・送り仮名の違いを吸収する | 元々の不満 |
| U2 | ジャンルでも引ける | 例: 「地図」で Google マップとヤフーマップの両方が出る。完璧でなくてよい |
| U3 | 利用者の負担を下げる | 別名を手で登録させるなら、ホーム画面を工夫するほうが早い。手動の登録に頼らない |
| U4 | 検索語とアプリの組を学習してよい | |
| U5 | ホーム画面を置き換えるランチャーである必要はない | 検索の道具でよい |
| U6 | 質の高いものを作って配布する | |
| U7 | 広告を出さない | T1 |
| U8 | 検索窓を画面の下に置ける | T3 |

## AI が補った要件（確認待ちのものを含む）

| # | 要件 | 根拠 | 状態 |
|---|---|---|---|
| A1 | 端末内で完結し、ネット接続の権限を持たない | プライバシー（インストールしたアプリの一覧を外に出さない）。Play の情報をオンラインで引く案は見送った | 合意済み（2026-10-27） |
| A2 | 素の Android と GrapheneOS の両方で動く | Google のサービスを持たない端末の利用者にも使えるようにする | 合意済み（2026-10-27） |
| A3 | 呼び出しが速い。デジタルアシスタント（画面の隅からのスワイプ・電源ボタン長押し）、クイック設定タイル、ホームのアイコンから開ける | U5 から。Material Search が同じ方式 | 要確認 |
| A4 | 配布経路に F-Droid（または IzzyOnDroid）を含める | 対象の利用者（プライバシーを重んじる人）は F-Droid でアプリを入れることが多い。Google Play を使う場合は `QUERY_ALL_PACKAGES` の審査がある | 要確認 |
| A5 | 日本語以外の端末でも壊れない | 配布するため | 要確認 |

## やらないこと（現時点）

- ホーム画面の置き換え（U5）
- 実行時に Play ストアの情報をオンラインで取得すること（A1。[decisions.md](decisions.md)）
- 端末内の埋め込みモデル（意味の近さでの照合）。サイズと短い入力への弱さのため、ほかの手がかりで足りなかったときに検討する
- アプリのショートカットの起動と、プライベートスペースのアプリ（どちらも既定のホームアプリにしか許されない。[android-platform.md](research/android-platform.md)）
