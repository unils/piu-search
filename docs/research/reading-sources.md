# 読みの手がかりの調査

調査日: 2026-10-27。アプリ名に読みを付けるための形態素解析器（文を単語に分けて読みを付けるソフト）と、英字のブランド名の読みの出どころを調べた。

## 形態素解析器

| 候補 | 版・状態 | 大きさ | メモ |
|---|---|---|---|
| Kuromoji（atilika）＋ IPADIC | 0.9.0（2015-09 から更新なし）。Apache-2.0。純 Java | `kuromoji-ipadic` の jar が 13.3 MB、`kuromoji-core` が 0.1 MB | YomiLauncher が Android で使っている（`com.atilika.kuromoji.ipadic.Tokenizer`） |
| Kuromoji ＋ UniDic | 同上 | jar が 46.3 MB | 大きすぎる |
| Lucene の Kuromoji（`lucene-analysis-kuromoji`） | 10.5.2（2026-10）。保守されている | — | Lucene 本体に依存する。Android での動作実績は確認できなかった（未検証） |
| Sudachi（Java） | 0.8.2（2026-09） | 辞書は別配布 | 大きさは未確認 |

出典: Maven Central のメタデータと jar の大きさ（`Content-Length`）。

### Kuromoji ＋ IPADIC の試し

手元の JVM（OpenJDK 25、デスクトップ PC）で、アプリ名らしい 53 語に読みを付けた。

- 初期化（辞書の読み込み）: 168 ms、ヒープの増加 35 MB。Android の端末ではこれより遅い見込みで、実機で測る
- 53 語の解析: 合計 6 ms（初期化の後）
- 正しかった例: 乗換案内・乗り換え案内 → ノリカエアンナイ（送り仮名の違いを吸収する）、ジョルダン乗換案内、三井住友銀行、日本経済新聞、雨雲レーダー、食べログ、出前館、大辞林
- 誤りか、揺れがある例:

| 語 | Kuromoji の読み | 問題 |
|---|---|---|
| ゆうちょ通帳アプリ | ユウチョ**カヨイチョウ**アプリ | 「通帳」を「かよいちょう」と読んだ。「つうちょう」で引けない |
| 日本郵便 | ニッポンユウビン | 正しいが、「にほん」と打つ人もいる |
| 明日の天気 | アシタノテンキ | 「あす」と打つ人もいる |
| Yahoo!天気・LINEマンガ・モバイルSuica | 英字の部分は読みが付かない（そのまま） | 英字のブランド名は別の手当てが要る |

読みは 1 語に 1 つしか出ない。複数の読みを持つ語の扱いは、評価セット（[testing.md](../design/testing.md)）で影響を見てから決める。

## 英字のブランド名の読み

「やふー」で Yahoo 系のアプリを出す（要件 T2）には、英字の綴りからかなの読みへの対応が要る。

| 出どころ | 内容 | ライセンス | 結果 |
|---|---|---|---|
| Mozc（Google 日本語入力の OSS 版）の辞書 `src/data/dictionary_oss/` | 読み→表記の約 129 万行 | 語彙は IPADIC 由来（Mozc の README） | 英字の表記は 937 行（MBS・SONY・NARUTO など）。Yahoo・Google・LINE・PayPay・Amazon などの英字表記は**ない**。カタカナ表記（ヤフー・グーグル・ペイペイ）はある |
| [e2k](https://github.com/Patchethium/e2k) | 英単語→カタカナの自動変換（小さな RNN）。2026-10 も更新中 | コードは Unlicense。学習データは CC-BY-SA（Wiktionary・JMdict） | 公称の完全一致率 67.1%。Python と Rust の実装のみ。学習済みの重みのライセンスの扱いは要確認 |
| [alkana.py](https://github.com/zomysan/alkana.py) | 英単語→カタカナの辞書 | GPL-2.0 | 2021 から更新なし |
| Material Search の `ShortcutData.kt` | 入力語→アプリ名の候補（約 2,500 行） | Apache-2.0 | 「やふおく」「やふしょ」はあるが「やふー」はない。値がアプリ名の文字列で、パッケージ名ではない |

結論: ブランド名の読みは、汎用の辞書からは取れない。**自前でブランド名の読みの表を作る**（数百語の規模）。英単語一般の自動変換（e2k の類）は、評価セットでブランド表だけでは足りないとわかったときに再検討する。
